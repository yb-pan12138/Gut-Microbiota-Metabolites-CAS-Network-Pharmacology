# Data provenance and public-release policy

The study integrates public or third-party resources with author-generated analyses. For public release, files should be separated into:

## Suitable for public release
- Author-written analysis scripts.
- Processed and derived target lists generated for the study.
- PPI/network-derived results.
- Enrichment-analysis outputs generated by the authors.
- Leave-one-database-out sensitivity results.
- Network-topology sensitivity results.
- Final SwissADME and ADMETlab summary tables generated for the manuscript.
- Processed molecular-docking score tables.
- Figure source data generated by the authors, where available.

## Review before public release
Raw or bulk exports retrieved from third-party resources, including resources whose terms may restrict redistribution, should be reviewed before upload. Where redistribution permission is unclear, provide the database name, retrieval date, query/filter criteria, and author-generated derived output rather than redistributing the raw export.

This policy is intended to preserve traceability without implying redistribution rights over third-party database content.
